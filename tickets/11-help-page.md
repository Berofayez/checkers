# #11: Help page

Status: done

## Goal
A "Help" button opens a new browser tab with plain-language instructions on
how to play, illustrated with diagrams.

## Done when
- [x] A "Help" button/link is visible next to "New game".
- [x] Clicking it opens a help page in a new browser tab (the game itself
      stays open and unaffected in the original tab).
- [x] The help page explains, in plain language: board setup, moving,
      mandatory jumping, multi-jump chains, kings, and how the game ends
      (win and draw).
- [x] The help page includes diagrams illustrating the starting position, a
      capture, and a king's movement.
