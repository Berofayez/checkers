# #2: Starting pieces

Status: done

## Goal
The board shows both players' pieces in their starting positions, along with
a static status line and piece counts.

## Done when
- [x] White's 8 pieces appear on the dark squares of rows 0–1.
- [x] Black's 8 pieces appear on the dark squares of rows 6–7.
- [x] Rows 2–5 are empty.
- [x] A status line reads "Black to move".
- [x] A piece count is shown for each player (8 and 8).
