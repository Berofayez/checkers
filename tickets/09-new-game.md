# #9: New game button

Status: not started

## Goal
A "New game" button resets the game to its starting state at any time.

## Done when
- [ ] A "New game" button is visible on the screen.
- [ ] Clicking it restores the starting board position for both players.
- [ ] It resets the turn to "Black to move", clears any selection, and
      resets piece counts to 8 and 8.
- [ ] It resets the no-capture/no-king counter used for draw detection.
- [ ] It works whether pressed mid-game, after a win, or after a draw.
