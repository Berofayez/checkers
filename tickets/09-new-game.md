# #9: New game button

Status: done

## Goal
A "New game" button resets the game to its starting state at any time.

## Done when
- [x] A "New game" button is visible on the screen.
- [x] Clicking it restores the starting board position for both players.
- [x] It resets the turn to "Black to move", clears any selection, and
      resets piece counts to 8 and 8.
- [x] It resets the no-capture/no-king counter used for draw detection.
- [x] It works whether pressed mid-game, after a win, or after a draw.
